# UART Transmitter using VHDL

## Overview

This project implements an 8-bit UART Transmitter using VHDL and a Finite State Machine (FSM). The design includes an integrated baud-rate generator and supports serial transmission of parallel input data.

## Features

- FSM-based UART Transmitter
- Integrated Baud Generator
- 8-bit Serial Data Transmission
- Start Bit and Stop Bit Generation
- Transmission Complete Flag
- Simulation Verified

## Tools Used

- VHDL
- Xilinx Vivado

## Project Structure

- src/ : Source Code
- testbench/ : Testbench Files
- simulation/ : Waveform Results
- docs/ : FSM Diagram

## Learning Outcomes

- RTL Design
- FSM Design
- UART Communication Protocol
- Digital System Verification
- VHDL Coding
